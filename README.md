# 因材施教 Agent 演示

这是一个面向高中生的个性化学习 Agent 静态演示版，当前包含数学与语文两个重点示例，并提供多学科入口。

演示内容包括：

- 数学几何证明：按“看已知，想性质；看求证，想判定”组织分步提示。
- 语文文学阅读：通过“找反常，追原因；作比较，品意味”引导学生分析真题材料。
- 知识地图：整合“读厚、读薄”以及章节知识关系。
- 错题本：按学科、章节、知识点和错题序号建立索引。
- 成长档案：展示知识点掌握度随练习与考试积累的变化。
